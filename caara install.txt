# goweslurmalangg cara clone agar sama semua

git clone https://github.com/sakhiasyam18/goweslurmalangg.git
cd goweslurmalangg
composer i

Nyalakan xampp
Buka phpMyAdmin
Klik tab “Databases”
Buat baru database kosongan:
iniajagoweslurmalangoktober

Lalu ubah .env:
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=iniajagoweslurmalangoktober
DB_USERNAME=root
DB_PASSWORD=

dan jalankan:
php artisan key:generate
php artisan migrate:fresh --seed
php artisan serve
http://localhost:8000/

kalau foto foto sepeda belum muncul
hapus folder yang ada di public/storage. hapus semuanya pokoknya sampai hilang folder storage nya sehingga tinggal 2 saja yaitu css dan images
download sepeda.zip dari drive ini "https://drive.google.com/file/d/1jcHOEf0jjwgleZYYowa7ZlXJuXNiQ2tL/view?usp=sharing"
esktrak zip nya 
tempelkan folder sepeda dari zip tadi ke dalam goweslurmalangg\storage\app\public
sehingga menjadi goweslurmalangg\storage\app\public\sepeda
php artisan storage:link

Hasilnya: database otomatis terisi semuanya
project langsung sama persis dengan punyamu.
